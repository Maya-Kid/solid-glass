## Start with shadcn/ui

Solid Glass is a theme for shadcn/ui, so it starts from a shadcn/ui project: React 19, Tailwind CSS 4, and the Base UI flavour of the components. If you do not have one yet:

```bash
npx shadcn@latest init
```

## Add the stylesheet

The whole material is one file. Put it beside your own styles; the command reads it straight from the [GitHub repository](https://github.com/deeplethe/solid-glass):

```bash
npx shadcn@latest add deeplethe/solid-glass/solid-glass
```

Add `#` and a tag or a commit to pin a version, as in `deeplethe/solid-glass/solid-glass#<commit>`. The same items are also served from this site, at `{origin}/r/<item>.json`, for a command line too old to read from GitHub.

Then import it after Tailwind and shadcn's stylesheet, and delete the `:root` and `.dark` colour variables that `shadcn init` wrote. Solid Glass defines the same names.

```css title="src/index.css"
@import "tailwindcss";
@import "tw-animate-css";
@import "shadcn/tailwind.css";
@import "./solid-glass.css";
```

The import above assumes the installed stylesheet is beside `src/index.css`. The command places it in your project's `src` directory when there is one, or at the project root otherwise. If your main stylesheet lives elsewhere, adjust the relative import to that installed file.

Dark is the material as designed. It follows the `dark` class on `<html>`. A project made by `shadcn init` has a `ThemeProvider` that sets that class from the system's setting; to start in dark whatever the system says:

```tsx title="src/main.tsx"
<ThemeProvider defaultTheme="dark">
```

Without a provider, put the class on the element yourself:

```tsx title="index.html"
<html lang="en" class="dark">
```

That's it. Every shadcn/ui component you already have is now Solid Glass, as shadcn/ui wrote it: the stylesheet finds each part by the `data-slot` and the classes it already carries, so there is nothing to edit and nothing to re-install.

## Add components

Stock components are installed the usual way, from shadcn/ui:

```bash
npx shadcn@latest add button
```

Solid Glass's own components are installed with the same command, from the repository:

```bash
npx shadcn@latest add deeplethe/solid-glass/status-glyph
```

## Self-hosted registries

To serve your own copy of the site and registry, build this repository with a matching full site URL and base path. For a domain root:

```bash
SOLID_GLASS_ORIGIN=https://design.example.com \
SOLID_GLASS_BASE=/ \
npm run build
```

For a subpath:

```bash
SOLID_GLASS_ORIGIN=https://example.com/design \
SOLID_GLASS_BASE=/design/ \
npm run build
```

`SOLID_GLASS_ORIGIN` includes the subpath, despite its name; it defaults to `https://deeplethe.github.io/solid-glass`. `SOLID_GLASS_BASE` defaults to `/`. Both are build-time settings. Serve `dist/` at the configured path and fall back to its `index.html` for client routes. If either location changes, rebuild; server environment variables cannot update already-built files.

Install from that registry by its URL:

```bash
npx shadcn@latest add https://example.com/design/r/status-glyph.json
```

Solid Glass's own dependencies in those served JSON files point to the configured site URL. The source registry in GitHub still uses `deeplethe/solid-glass/<item>` addresses, and installing by that GitHub address continues to use GitHub, regardless of where you host the site.

Self-hosting only serves the items Solid Glass publishes. Stock components such as `button` and `kbd` still come from shadcn/ui, and packages still come from npm or your configured package mirror. A fully offline installation needs those sources prepared too.

## Fonts

The stylesheet sets `--font-sans` to Geist and `--font-mono` to Geist Mono, and falls back to the system's. To use them, add the font files yourself:

```bash
npm install @fontsource-variable/geist @fontsource-variable/geist-mono
```

```css title="src/index.css"
@import "@fontsource-variable/geist";
@import "@fontsource-variable/geist-mono";
```
